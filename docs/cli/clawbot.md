# `nova-ai clawbot`

Legacy alias namespace kept for backwards compatibility.

- `nova-ai clawbot qr` (same behavior as [`nova-ai qr`](/cli/qr))

## Migration

Prefer modern top-level commands directly:

- `nova-ai clawbot qr` -> `nova-ai qr`
